# UP Design System

**Guía de Estilo Institucional — Universidad Panamericana**

Sitio estático con 6 pantallas del Design System institucional de UP, desarrollado con Tailwind CSS.

## Páginas

| # | Archivo | Descripción |
|---|---------|-------------|
| — | `nav.html` | Índice de navegación |
| 01 | `index.html` | Guía de Estilo Institucional |
| 02 | `admissions-login.html` | Portal de Admisiones – Login |
| 03 | `admissions-dashboard.html` | Admissions Dashboard |
| 04 | `course-details-1.html` | Course Details – Educational Leadership |
| 05 | `course-details-2.html` | Course Details – International Business Strategy |
| 06 | `iconografia.html` | Biblioteca de Iconografía y Componentes UP |

## Uso

Abre `nav.html` en tu navegador para navegar entre todas las páginas.

> Requiere conexión a internet para cargar Tailwind CSS CDN y Google Fonts.

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Google Fonts: EB Garamond, Inter, Noto Serif, Libre Caslon
- Material Symbols Outlined
